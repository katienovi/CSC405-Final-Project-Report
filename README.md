# CSC405-Final-Project-Report
This is my final project report for CSC 405 (Data Science).


Project title: Exploring Seasonal Patterns in Renewable Energy Consumption.


Dataset source (URL): https://www.kaggle.com/datasets/alistairking/renewable-energy-consumption-in-the-u-s 


Project objective: The objective of this Data Science project was to examine how the four seasons, Spring, Summer, Fall, and Winter, impact the consumption of renewable energy in the United States. More specifically, this project examines energy consumption across a range of renewable energy sources, including solar, wind, hydroelectric, and geothermal, from 1973 to 2024, noting not only the seasonal trends, but also *why* these trends might have occurred in the context of renewable energy interests in the United States.
